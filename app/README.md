# 本地多图拼接界面

便携 Demo：完整解压 `Multicamara-Demo-Windows-x64.zip` 后，双击根目录的 `Start-Demo.bat` 或 `app/start.bat`。包内含独立运行环境、依赖和模型，无需安装 Python。启动后点击“选择图片文件夹”导入自己的数据集，详见包内 `使用说明.txt`。启动器优先使用 `runtime/python.exe`；源码项目仍可使用现有 `.venv`。

Windows 10：双击 **app/start.bat**。浏览器会打开 `http://127.0.0.1:8765`；运行期间保留启动窗口，关闭服务可在该窗口按 Ctrl+C。无需安装 Node、Flask 或其他新依赖，使用项目现有 `.venv`。

也可以在 `multicamara` 目录运行：

```powershell
.\.venv\Scripts\python.exe .\app\server.py --open
```

端口占用时使用 `--port 8766 --open`。

## 使用

1. 点击「选择图片文件夹」，在浏览器文件夹选择器中确认导入。
2. 只显示目录同一级支持的图片；按文件名自然排序，默认不选中 `ground_truth.png` / `gt.png` 等参考图。可手动勾选或排除图片，至少选择 2 张。
3. 在导入模块的「前处理方式」下拉框中选择「无前处理」「去雾」或「暗光增强 · 自然光照增强」。使用原图时可直接拼接；选择其他方式时先点击「应用」。去雾调用 `dehaze.py`；暗光增强调用 `enhance_lowlight.py` V2，使用现有的光照估计、去噪、受限增益与颜色保护。只处理当前勾选的图片，保留源尺寸。
4. 处理完成后，待拼接缩略图自动切换为处理结果。暗光增强显示的是**自然增强图**，可用「查看原图 / 查看自然增强图」比较，并点击缩略图右上角 ⤢ 放大自然增强图。切换预览只改变显示，不改变后续拼接输入；界面会明确显示当前输入是原图、去雾结果或自然增强图。
5. 有重叠的图片使用「自动拼接」；无重叠的已知裁块使用「网格排列」，填写每行图片数，按当前文件名顺序排列。
6. 点击「开始拼接」。已经应用前处理时，后端直接使用当前任务保存的处理后 PNG，不重新上传原图。暗光自动拼接时，SIFT 使用独立的配准辅助图，HED 和最终全景像素使用自然增强图；辅助图不在界面展示，也不用于最终成像。网格排列直接放置自然增强图，不运行配准。前处理完成后仍可修改拼接模式或融合方式。前处理或拼接失败时均显示实际原因及日志。
7. 成功后查看预览、输出宽高与像素数，点击「下载原尺寸 PNG」。页面上的全景预览最长边 1800 像素，单张前处理缩略图长边最多 640 像素，下载和拼接始终使用完整分辨率文件。

更换文件夹、修改勾选或切换前处理方式会清除当前前处理关联，恢复原图预览。选择前处理但尚未应用、或前处理失败时，「开始拼接」不可用，防止误用旧结果。切回「无前处理」即可恢复使用原图。每个处理任务只执行一次拼接；需要再次使用同一批图片拼接时，可再次点击「应用」创建新的前处理任务。

选择文件夹使用浏览器的 `webkitdirectory` 接口，推荐 Windows 上的 Edge/Chrome。图片只通过回环地址传递给本机 Python 服务，不发送到外部服务。单张图片上限 512 MB，每次任务总计上限 4 GB，最多 100 张；同一时刻只运行一个拼接计算任务。

每个任务保存到 `multicamara/output/web/<任务ID>/`：`inputs` 输入副本、可选 `processed` 前处理结果与报告/缩略图、`preprocess.log`、`result.png`、标定 `.npz`、报告、可选全景 `preview.jpg`、完整 `run.log` 和最终 `status.json`。暗光处理的 `processed/*.png` 为自然增强图，`processed/registration/*.png` 为配准辅助图，`processed/previews/*.jpg` 仅从自然增强图生成。重新应用会新建任务，不覆盖源图或前一次结果。拼接任务链接在服务保持运行时可以刷新恢复；尚未开始拼接的前处理状态不随页面刷新恢复，服务重启后也需要重新导入，历史磁盘结果仍然保留。

更新界面代码后，请先关闭旧服务窗口，再双击 `start.bat`，并刷新浏览器页面。启动器和依赖均不变。

后端通过独立 Python 子进程调用现有 `ges.cli`，保持现有算法和命令行工具可用。自动模式使用 HED，需要项目 `models` 下已有模型。进度条是阶段提示，不是剩余时间估计。网格模式支持原像素布局；其他模式仍受几何配准质量、系统内存和 1.2 亿画布预算约束。当前输入读取为 8 位 BGR。

## 验证

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s app -p test_server.py -v
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

`test_frontend.mjs` 导出的 `runTests()` 可由 Node 执行，覆盖两种前处理的选择、预览切换、放大、处理结果复用、过期结果失效及失败提示。这是前端状态测试，不替代浏览器文件夹选择器的视觉检查。界面运行不需要 Node。
